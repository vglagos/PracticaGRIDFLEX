# Ejercicios para alumnos

## Ejercicio 1 — Crear un menú con Flexbox

Construye un menú horizontal con:

```
Inicio
Productos
Contacto
Blog
```

Requisitos:

- usar `display:flex`

---

## Ejercicio 2 — Crear un layout con Grid

Construye un layout con:

- header
- sidebar
- contenido principal
- footer

Usando:

```
grid-template-columns
grid-template-rows
```

---

## Ejercicio 3 — Galería de imágenes con Grid

Crea una galería con **4 imágenes en cuadrícula**.

Requisitos:

- usar `display:grid`
- usar `repeat()`
- añadir `gap`

---

## Ejercicio 4 — Tarjetas con Flexbox

Crea un contenedor con **3 tarjetas**.

Requisitos:

- usar `display:flex`
- todas las tarjetas deben tener el mismo ancho
- añadir separación entre ellas

---

## Ejercicio 5 — Versión responsive

Adapta el ejercicio anterior para móvil:

- las tarjetas deben pasar de **fila a columna**
- usa `flex-direction`
- usa `@media`
